Winisland 0.7.0 simplifies Spotify account connection, smooths activity changes, and reduces work while views are hidden.

- Connect your Spotify account directly from **Settings → Player controls → Connect Spotify**, without entering a developer Client ID. Premium and approval for Winisland's Spotify app are required. Settings explain account approval failures and offer account switching; available local controls continue working when the account API is unavailable.
- Activity and chooser transitions preserve their displayed position and spring velocity when interrupted. Returning to the same activity animates correctly, departing controls yield keyboard focus, and completed animations release their clocks. Reduced motion remains supported.
- Suspend recurring player-volume reads and hidden player rendering when the notch is closed, hidden, minimized, or showing another activity. Native pointer movement prepares controls as you approach. Real volume changes, pending writes, reminders, notifications, and visible compact activities retain their behavior.
- Fix a notification-layout reference that could retain closed Settings windows. Notification sizing now completes normal WPF layout, and a strict lifetime check confirms Settings can be collected.
- Fix browser companion handoff races and stale reports from departing documents. Calendar import now respects daylight-saving transitions for day/week durations and preserves all-day calendar dates.
- Expand private-desktop verification for Spotify authorization, interrupted motion, view lifetimes, browser reconnection, and calendar round trips. Installer lifecycle checks run in a disposable Windows VM; the release includes verification reports and build provenance.
