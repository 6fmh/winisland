Winisland is now open source under the MIT license.

- Choose your own HTTPS upload server. No server is preconfigured, including for older token-only profiles. Import compatible ShareX uploaders or enter a server URL and optional token.
- New releases appear on the closed notch and in a Software update tab. Choose **Update and restart** to download, verify and install the update; cancel while downloading if you want to wait.
- Faster first-notch rendering. Secondary panels and integrations load after the first frame; packaged code is precompiled and the application bundle needs no decompression at launch.
- Start immediately at sign-in with an account-specific logon task. The installer offers startup enabled by default; in-app updates preserve your saved preference.

Download **Winisland-Setup-0.4.0-win-x64.exe** below. It includes the .NET runtime and installs for the current Windows account without administrator rights. Its adjacent `.sha256` file contains the download checksum. Windows 10 version 2004 or later and Windows 11 are supported.

Settings, encrypted connections, notes and file references are preserved during updates. Older upload credentials require choosing a server again. This installer is unsigned.
