Winisland 0.5.0 adds notch notifications, refines the native interface, and improves idle reliability.

- Incoming visible Windows notification banners appear in the notch with an app icon, sender and preview. Hover to expand; dismiss or use the notification's supported action. Windows notification settings and Do Not Disturb remain in control.
- Refined notch and settings typography, spacing, keyboard focus, press feedback and reduced-motion behavior. Apple-device connection moments show clearer device names and model details.
- Lower startup memory through deferred organizer panels and Spotify controls, shared reminder scheduling, and bounded artwork that releases its encoded buffer.
- Recover notch visibility after power resume, session unlock and display changes. Idle maintenance restores a hidden, minimized or displaced notch while preserving fullscreen hiding.

Download **Winisland-Setup-0.5.0-win-x64.exe** below. It includes the .NET runtime and installs for your Windows account without administrator rights. The adjacent `.sha256` file contains its download checksum. Windows 10 version 2004 or later and Windows 11 are supported.

Updates preserve settings, encrypted connections, notes and file references. The installer is unsigned. Notification capture depends on the Windows shell exposing its visible banner through accessibility; it does not replay notification history.
