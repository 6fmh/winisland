Winisland 0.6.0 adds an optional Dynamic Island appearance, refines everyday interactions, and improves update, file, device and music reliability.

- Choose **Settings → Appearance → Notch style → Dynamic Island** for a floating pill, compact music and separate timer activity, an expanded player, and a keyboard-accessible **…** menu. MacBook notch remains the default; switching back restores its saved dimensions.
- Refined panel spacing, focus and press feedback, notification expansion and dismissal, accessory connection moments, and reduced-motion behavior. AirPods identification uses available Windows metadata and preserves uncertain model names.
- More reliable updates, with clearer release notes and download feedback, stable-release selection, checksum validation, cancellation and retry handling, and installer rollback safeguards. Public builds retain automatic update checks; personal builds disable them.
- Fixed file-shelf interactions and upload cancellation/progress handling, calendar import and organizer edge cases, Spotify credential refresh, browser companion reconnection, and playback state synchronization.
- Reduced browser native-host startup and memory, upload-processing allocations and notifications, and timeline text allocations. Controlled measurements did not show a reliable reduction in the main application's idle RAM or CPU; see [performance results](https://github.com/6fmh/winisland/blob/v0.6.0/docs/PERFORMANCE.md).
- Expanded private-desktop native verification, browser safety checks, and disposable-VM installer lifecycle checks. Added contributor, notification, design and audit documentation.

Download **Winisland-Setup-0.6.0-win-x64.exe** below. It includes the .NET runtime and installs for your Windows account without administrator rights. The adjacent `.sha256` file contains its download checksum. **Winisland-Verification-0.6.0.zip** includes verification reports and source/build provenance. Windows 10 version 2004 or later and Windows 11 are supported.

Updates preserve settings, encrypted connections, notes and file references. The installer is unsigned. Notification capture depends on Windows exposing its visible banners through accessibility; it does not replay notification history. Apple accessory details and media controls depend on the capabilities Windows and the player expose.
